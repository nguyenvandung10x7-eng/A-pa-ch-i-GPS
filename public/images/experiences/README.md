# Experience Card Images

Store future hero images for the experience cards in this folder.

Update flow:
1. Copy your new image into this folder.
2. Open src/data/experiences.ts.
3. Update only the image path of the target card, for example:
   image: '/images/experiences/my-new-image.webp'

Recommended format:
- Aspect ratio: 16:10 or 4:3
- Minimum size: 1600x1000
- Preferred type: .webp
